# Classic II Reloaded

Started with my reverse-engineered later-revision [Classic II](../ClassicIIRevB/), and made some changes for convenience:

- Can use ROM chips from the earlier or later revisions.
- Should be able to use more "modern" 12mm right-angle pushbuttons.
- Can use a 2032 battery.
- Late revision jumper block made no sense, use separate jumpers like the earlier-revision.
- Electrolytic capacitor pads wide enough to safely accomodate tantalum capacitors.
